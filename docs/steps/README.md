# Note de pas

La finalul fiecărui pas se scrie o notă `NN-nume.md` (de exemplu `00-schelet.md`, `03a-tempo-ton.md`).
Sesiunea următoare pornește de la ultima notă.

## Șablon

```markdown
# Pasul NN — <nume>

## Ce am găsit înainte
3–5 rânduri: ce exista deja, ce convenții folosește codul, unde se leagă pasul.

## Plan
| Fișier | Nou / schimbat | De ce | Cine îl folosește |
| --- | --- | --- | --- |

## Ce s-a făcut
- …

## Decizii
- … (trecute și în docs/decisions.md)

## Cum testezi
- comenzi și pași de mână

## Ce rămâne / atenție pentru pasul următor
- …
```
