# Machete — doar referință vizuală

Fișierele `.dc.html` sunt sursa machetelor de pe canvasul de design
(https://claude.ai/artifact/QVeK1q9AuiuF8ddLfzo2T3). Folosesc un format de șablon al
editorului de design (`<x-dc>`, `{{…}}`, `<sc-for>`) și **nu sunt cod de producție**. Nu le
importa, nu le copia ca atare și nu le deschide direct în browser: depind de un `support.js`
care nu există aici.

Folosește-le ca să citești structura, ierarhia, spațierea și textele fiecărui ecran.
Valorile de stil oficiale sunt în `docs/design.md`.

| Fișier | Ecran |
| --- | --- |
| `Main.dc.html` | Biblioteca |
| `Builder.dc.html` | Constructorul de mix |
| `Transition.dc.html` | Editorul de tranziție |

Numele pieselor și artiștilor din machete sunt inventate, doar ca exemplu.
